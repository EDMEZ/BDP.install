# Biblioteca das Platinas — instaladores

Biblioteca de jogos pessoal com troféus no estilo PlayStation (Windows).

## Como instalar
1. Abra a aba **Releases** (lado direito desta página) e clique na versão mais nova.
2. Baixe o arquivo **Biblioteca das Platinas Setup X.Y.Z.exe** (em "Assets").
3. Dê dois cliques para instalar.
4. Se o Windows mostrar "O Windows protegeu seu computador": clique em **Mais informações** e depois em **Executar assim mesmo**. O aviso aparece porque o instalador não é assinado (assinar custa dinheiro).

## Atualizações
Depois de instalado, o app procura versão nova sozinho ao abrir. Todas as versões antigas continuam disponíveis em Releases.
